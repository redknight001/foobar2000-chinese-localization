# foobar2000 中文汉化组件

让熟悉的音乐播放器，用更顺手的中文陪你听音乐。

本仓库发布由 Charles 制作的 foobar2000 汉化组件及使用说明，仅提供编译后的组件，不公开源代码。当前稳定版本为 **v0.5.13**。

组件在运行时翻译界面文字，无需修改 foobar2000 主程序。支持统一中英词库、逐条调整、自动收集英文，以及交给 AI 批量翻译后导入合并。

## 下载与安装

请在 [Releases 发布页面](https://github.com/redknight001/foobar2000-chinese-localization/releases/tag/v0.5.13) 下载 v0.5.13 分发包，解压后通过 foobar2000 的 **首选项 → 组件 → 安装** 安装其中的 `.fb2k-component` 文件，应用并重启。

适用于 **Windows x64 的 foobar2000 2.26 / 2.26.1 / 2.26.2**，本次在 2.26.2 x64 安装版验证；具体验证范围见下文。安装版与便携版使用相同组件。其他版本、32 位版本及所有第三方组件尚未全面验证。

## v0.5.13 更新

针对部分用户在 foobar2000 2.26.2 中遇到的菜单子项点击无反应问题，调整菜单翻译时机，移除菜单弹出后的显示事件和位置消息改写。在宿主原有菜单创建、更新及弹出前翻译文字，保持原命令分发参数与返回值。

本机 foobar2000 2.26.2 x64 + Columns UI 3.7.1 已实测首选项、控制台、右键属性、二级 DSP／均衡器与退出正常执行，菜单保持中文。原受影响试用者的环境仍待回测，本次为针对性修补，不保证所有环境已解决。

保留快速汉化面板、现有布局、主题跟随及词库管理功能。Charles 完整词库 4515 条已内置组件 DLL，分享包不附独立 TSV；可从设置页导出备份。

深度汉化，99%，持续完善：“99%”是持续改进的表达，并非量化测得的覆盖率，永远保留 1%。

## 特色

- 常见菜单、设置页、标准控件及部分组件界面汉化。
- 界面跟随主程序的浅色、深色主题。
- 一份中英词库，支持搜索和逐条编辑。
- 自动收集新英文，支持只导出未翻译词条。
- AI 翻译后导入，自动去重并由用户处理译文冲突。
- 空译文不会覆盖已有译文，修改前自动备份。
- 编辑或导入有效修改后，点击确定或应用会提示重启。

## 使用与反馈

进入 **首选项 → 工具 → 汉化**。完整说明见 [使用说明](USAGE.md)。

欢迎通过 Issues 反馈界面英文遗漏、译文问题和新版本兼容情况。反馈时请注明 foobar2000 版本、位数、相关组件和操作步骤；分享截图或词库前请移除个人路径、设备信息等隐私内容。

图片文字、自绘控件及未触发的动态界面可能无法覆盖。同一英文在不同语境下目前共享译文。
