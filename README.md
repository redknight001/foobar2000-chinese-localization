# foobar2000 中文汉化组件

让熟悉的音乐播放器，用更顺手的中文陪你听音乐。

本仓库发布由 Charles 制作的 foobar2000 汉化组件及使用说明，仅提供编译后的组件，不公开源代码。当前稳定版本为 **v0.5.14**。

组件在运行时翻译界面文字，无需修改 foobar2000 主程序。支持统一中英词库、逐条调整、自动收集英文，以及交给 AI 批量翻译后导入合并。

## 下载与安装

请在 [Releases 发布页面](https://github.com/redknight001/foobar2000-chinese-localization/releases/tag/v0.5.14) 下载 v0.5.14 分发包，解压后通过 foobar2000 的 **首选项 → 组件 → 安装** 安装其中的 `.fb2k-component` 文件，应用并重启。

适用于 **Windows x64 的 foobar2000 2.26 / 2.26.1 / 2.26.2 / 2.26.3**，2.26.3 已通过自动兼容性回归。安装版与便携版使用相同组件。其他版本、32 位版本及所有第三方组件尚未全面验证。

## v0.5.14 更新

新增 **foobar2000 2.26.3 x64** 适配。新版默认界面恢复专辑封面占位文字（如 `[no image]`）及部分主题菜单文字的汉化。保留旧版适配和 0.5.13 的菜单命令分发逻辑。

内置 Charles 完整中英词库 4515 条，内容与 0.5.13 一致。完整分享包包含组件、使用说明和许可证。

通过 **首选项 → 组件 → 安装** 选择 `foo_localization-0.5.14.fb2k-component`，点击应用并重启。安装版与便携版使用同一组件。

自动回归已通过 25 项菜单与版本检查、9 项词库检查及 511 项布局检查。2.26.3 播放器内的实际鼠标点选仍待验证。

## 特色

- 常见菜单、设置页、标准控件及部分组件界面汉化。
- 界面跟随主程序的浅色、深色主题。
- 一份中英词库，支持搜索和逐条编辑。
- 自动收集新英文，支持只导出未翻译词条。
- AI 翻译后导入，自动去重并由用户处理译文冲突。
- 空译文不会覆盖已有译文，修改前自动备份。
- 编辑或导入有效修改后，点击确定或应用会提示重启。

## 使用与反馈

进入 **首选项 → 工具 → 汉化**。完整说明见 [使用说明](USAGE.md)。

欢迎通过 Issues 反馈界面英文遗漏、译文问题和新版本兼容情况。反馈时请注明 foobar2000 版本、位数、相关组件和操作步骤；分享截图或词库前请移除个人路径、设备信息等隐私内容。

图片文字、自绘控件及未触发的动态界面可能无法覆盖。同一英文在不同语境下目前共享译文。
