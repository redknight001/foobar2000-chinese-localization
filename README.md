# foobar2000 中文汉化组件

让熟悉的音乐播放器，用更顺手的中文陪你听音乐。

本仓库发布由 Charles 制作的 foobar2000 汉化组件及使用说明，仅提供编译后的组件，不公开源代码。当前稳定版本为 **v0.5.5**。

组件在运行时翻译界面文字，无需修改 foobar2000 主程序。支持统一中英词库、逐条调整、自动收集英文，以及交给 AI 批量翻译后导入合并。

## 下载与安装

请在 [Releases 发布页面](https://github.com/redknight001/foobar2000-chinese-localization/releases/tag/v0.5.5) 下载 v0.5.5 分发包，解压后通过 foobar2000 的 **首选项 → 组件 → 安装** 安装其中的 `.fb2k-component` 文件，应用并重启。

适用于 **Windows x64 的 foobar2000 2.26 / 2.26.1**，本版已在 2.26.1 x64 安装版进行界面抽查。安装版与便携版使用相同组件。其他版本、32 位版本及所有第三方组件尚未全面验证。

## v0.5.5 更新：深度汉化，99%，持续完善

本版进行了深度汉化，汉化比例提升到 **99%**。“99%”表达的是持续完善的使用体验，并非量化测得的覆盖率；永远保留 1%，代表继续改进，不自称完全。

- 扩展窗口标题、标签、布局元素分组及排序下拉框汉化。
- 改善程序自动命名的播放列表在不同入口的中文显示，保留用户自定义名称。
- 修复菜单功能说明匹配，补充底部状态栏说明及控制台固定日志、错误原因的中文显示。
- 内置 **3693 条**通用词条，延续词库编辑、导入导出、去重合并及主题跟随功能。
- 继续保护歌曲、专辑、艺术家、歌词、文件路径及用户自定义内容。

发布构建通过 **381 项**程序路径及内容保护检查，实机抽查包含六层布局入口在内的多个分支。部分第三方或自绘界面仍可能存在遗漏。历史发布保留，可用于回退。

## 特色

- 常见菜单、设置页、标准控件及部分组件界面汉化。
- 界面跟随主程序的浅色、深色主题。
- 一份中英词库，支持搜索和逐条编辑。
- 自动收集新英文，支持只导出未翻译词条。
- AI 翻译后导入，自动去重并由用户处理译文冲突。
- 空译文不会覆盖已有译文，修改前自动备份。
- 编辑或导入有效修改后，点击确定或应用会提示重启。

## 使用与反馈

进入 **首选项 → 工具 → 汉化**。完整说明见 [使用说明](USAGE.md)。

欢迎通过 Issues 反馈界面英文遗漏、译文问题和新版本兼容情况。反馈时请注明 foobar2000 版本、位数、相关组件和操作步骤；分享截图或词库前请移除个人路径、设备信息等隐私内容。

图片文字、自绘控件及未触发的动态界面可能无法覆盖。同一英文在不同语境下目前共享译文。
